Bitcoin Wallet Basics

A wallet manages keys. Bitcoin itself remains recorded on the Bitcoin network.

Private key

Secret key material used to authorize spending. Whoever controls the private key can usually control the associated bitcoin.

Public address

An address can receive bitcoin and can generally be shared. It is not the same as the private key.

Seed phrase

A human-readable backup from which wallet keys can be regenerated.

Why backups matter

Hardware can fail, be lost, or be destroyed. The recovery method determines whether access can be restored safely.
