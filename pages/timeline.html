HISTORY

History & Timeline

How modern wallet recovery concepts developed.

1979
Adi Shamir publishes Shamir’s Secret Sharing.
2012
BIP-32 introduces hierarchical deterministic wallets.
2013
BIP-39 introduces mnemonic code for deterministic keys.
2014
BIP-44 describes a multi-account hierarchy.
2017
SLIP-0039 is created as a standard for Shamir-based mnemonic recovery shares.
Today
Custody designs include BIP-39 backups, SLIP-39 recovery, multisig, and hybrid structures.
